About

SmartKit Tool is a collection of free online tools for everyday tasks. We build each tool to be fast, simple and easy to use on both phones and computers.

Our first tools help with text: counting words and characters, changing letter case, removing duplicate lines and cleaning extra spaces. We add new tools based on what visitors ask for.
